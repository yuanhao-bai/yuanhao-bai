## Selected Research Project

### Edge-Assisted Multimodal Perception and HIL-Oriented Prototype for NEV Thermal Runaway Intervention

A safety-critical embedded CPS prototype for early warning and physical intervention in new energy vehicle (NEV) thermal runaway scenarios, with attention to enclosed underground parking environments.

**System architecture and technical scope**

- **Edge node (current):** Jetson Nano
- **Real-time control node:** ESP32
- **Control timing logic:** timer-based sequential control design with microsecond-level timing concept
- **Thermal sensing (current):** 80×62 infrared thermal sensor
- **Gas/smoke indication:** MQ-2 used for threshold-based smoke/gas indication
- **Vehicle telemetry interface:** proposed GB/T 27930 integration and planned simulated BMS input
- **Decision reliability:** internal-external consistency checking to reduce false alarms
- **Multimodal fusion logic:** dynamic weighted evaluation model
- **Electrical isolation:** TLP250H optocoupler isolation for high-voltage safety-controlled prototyping
- **Prototype test platform:** 390V electromagnetic ejection testbed for safety-controlled prototyping and HIL-oriented validation
