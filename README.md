## Featured Project

### Edge-Assisted Multi-Modal Perception and HIL Validation for NEV Thermal-Runaway Intervention

A safety-critical embedded CPS prototype integrating edge perception, real-time actuator control, multi-modal sensing, and high-voltage experimental validation for early warning and physical intervention of new energy vehicle thermal runaway.

Key components and technical highlights:

- NVIDIA Jetson Orin Nano as the edge intelligence node
- ESP32 as the real-time actuator control node
- Timer/interrupt-based actuator sequencing with 50 μs inter-channel spacing
- MLX90640 infrared thermal matrix sensing
- MQ-2 gas sensing
- GB/T 27930-based BMS telemetry integration
- Internal-external consistency checking for reducing false alarms
- Dynamic weighted evaluation model for multi-modal decision-making
- TLP250H optocoupler isolation for high-voltage safety prototyping
- 390V electromagnetic ejection testbed for HIL-style validation

Status: Chinese Invention Patent Application No. 202610514577.7, First Inventor. Manuscript in preparation.
